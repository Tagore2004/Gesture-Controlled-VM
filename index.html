Gesture Controlled Virtual Mouse

AI-powered Human–Computer Interaction using Hand Gestures

Control Your Computer with Just Your Hand

This system uses MediaPipe, OpenCV, and Machine Learning to interpret hand gestures and translate them into mouse movements and actions. A modern, contactless, and intuitive interaction experience.

🔥 Project Overview

The Gesture Controlled Virtual Mouse replaces the traditional physical mouse with gesture inputs. It recognizes index finger movement for cursor control, pinch gestures for clicks, and other hand shapes for scrolling, dragging, and double-click actions.

✨ Features

  • ✔ Real-time hand tracking
  • ✔ Cursor movement controlled by index finger
  • ✔ Click detection using thumb–index pinch
  • ✔ Supports scrolling, dragging, and double-click gestures
  • ✔ Built using machine learning + computer vision
