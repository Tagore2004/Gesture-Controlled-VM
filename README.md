# Gesture Controlled Virtual Mouse

A computer vision–based mouse control system using hand gestures.  
Built with **Python, OpenCV, MediaPipe, NumPy, and PyAutoGUI**.

## 🚀 Overview
This project replaces traditional mouse devices with hand gestures.  
Using a webcam, it tracks hand landmarks and maps finger positions to mouse movements.

## ✨ Features
- Real-time hand tracking  
- Cursor control using index finger  
- Click detection using thumb-index pinch  
- Smooth and responsive control  
- Built using lightweight ML models  

## 🛠️ Technologies Used
- Python  
- OpenCV  
- MediaPipe  
- NumPy  
- PyAutoGUI
